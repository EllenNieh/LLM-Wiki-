# Smart Contract Security Wiki

Course project phase 1: ingest public technical documentation into a local, source-traceable SQLite FTS5 Wiki.

## Setup (Windows PowerShell)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python workflow/ingest.py
python workflow/search.py "reentrancy security"
```

Use Python 3.11 or 3.12. If PowerShell blocks activation, run `.venv\Scripts\python.exe` instead of `python` for the commands.

## What to inspect

- `sources/manifest.json`: seven candidate official documentation URLs
- `sources/raw/Sxx.txt`: cleaned extracted text (generated by ingest)
- `index/wiki.db`: searchable SQLite database (generated by ingest)
- `logs/ingest_log.json`: fetch results, retries, source counts (generated by ingest)

The ingest script exits with an error if fewer than five sources succeed. An HTTP success alone does not count: extracted text must be at least 500 characters. It saves source URL, retrieval time, SHA-256 and chunk identifiers. Sources can change or block requests; inspect the log and adjust URLs or parsing before accepting results.

## Important limitations

- Phase 1 only: no LLM generation, content fact-check graph, or HTML slide generation yet.
- FTS5 `unicode61` works best with English technical terms. Add Chinese-to-English terminology expansion in phase 2.
- Automatic text extraction can include unrelated site content; manual sampling and cleaning checks are required.
- This package does not contain downloaded source articles; run ingest locally with internet access.
- Respect each site's access policy and attribution requirements.
